# UI Context & Design System Tokens

## 1. Aesthetic Direction
- Theme: Dark Mode first (Technical, Minimalist, Precision Engineering).

## 2. Color Tokens (Mapped to CSS Variables in globals.css)
- **Backgrounds**:
  - `--bg-primary`: `#0a0a0c` (Canvas / Main background)
  - `--bg-secondary`: `#121216` (Sidebar / Panels)
  - `--bg-surface`: `#1a1a22` (Cards / Dialogs / Popovers)
  - `--bg-hover`: `#262632`
- **Text & Content**:
  - `--text-primary`: `#f5f5f7` (Headings, primary labels)
  - `--text-muted`: `#8e8e93` (Secondary descriptions)
  - `--text-faint`: `#505060` (Disabled / Placeholders)
- **Brand & Accents**:
  - `--accent-primary`: `#6366f1` (Indigo primary)
  - `--accent-hover`: `#4f46e5`
  - `--accent-subtle`: `rgba(99, 102, 241, 0.15)`
- **Borders**:
  - `--border-subtle`: `#27272a`
  - `--border-focus`: `#6366f1`

## 3. Typography & Spacing
- Primary Font: Inter / Outfit / Sans-serif.
- Code / Monospace Font: JetBrains Mono / Monospace.
- Border Radius: `rounded-lg` (8px) for containers/cards; `rounded-md` (6px) for buttons/inputs.
